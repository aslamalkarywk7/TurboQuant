# Support

## Where to ask

1. **Docs first:** [README](README.md) → [FAQ](docs/FAQ.md) → [TROUBLESHOOTING](docs/TROUBLESHOOTING.md) → [API](docs/API.md) — hub: [docs/README](docs/README.md)
2. **Bugs:** open an Issue with the bug template (version, OS, Python, repro file size/type, command, full traceback, `bench` output)
3. **Features:** open an Issue with the feature template (use case, why existing `modes`/`advanced` do not solve it)
4. **Security:** do NOT open an issue — see [SECURITY](SECURITY.md)

## Response expectations

- Maintainers are volunteers. Docs issues and repro-backed bugs get priority.
- PRs following [CONTRIBUTING](CONTRIBUTING.md) + green `pytest tests -q -rs` are reviewed first.
