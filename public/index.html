    How to use (30 seconds)
    1. Pick a task above: Smart auto for anything, Lossless for max safety, Image for tiny photos, Decompress for .tqz files.
    2. Adjust settings freely: compression mode, advanced transforms, image target size + format, response as binary or JSON+base64.
    3. Drop files into the box (or Browse), press Run, watch the progress bar, read the stats, then Download.
    4. Trust but verify: Analyze + certificate shows entropy and PASS/FAIL, Benchmark compares modes on your file.
    Deploy on Vercel: upload this folder as-is → vercel --prod. UI lives in /public/index.html, API in /api/*.py. Locally: python -m turboquant serve --port 8765 then open http://localhost:8765/.
