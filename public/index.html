📖 How to use (30 seconds)
  1. Pick a task below: Auto (recommended) for anything, Lossless for max safety, Image 800KB for tiny photos, Decompress for .tqz files.
  2. Choose your options freely: compression mode (fast → ultra), advanced transforms for extra ratio, image target size + format, response as binary download or JSON+base64.
  3. Drop files into the box (or Browse). On Vercel one request ≈ 4.5MB max — for bigger files run locally: python -m turboquant serve.
  4. Press ▶ Run, watch the progress bar, read the stats (original → new, codec, verified), then ⬇ Download.
  5. Trust but verify: use Analyze + Certificate to see entropy, suggested pipeline and PASS/FAIL, or Benchmark to compare modes on your file.
