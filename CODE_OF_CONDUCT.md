# Contributor Covenant Code of Conduct v2.1 (abridged adoption)

## Our pledge

We pledge to make participation harassment-free for everyone, regardless of age, disability, ethnicity, gender, experience, nationality, or religion.

## Expected behavior

- Use welcoming language. Respect differing viewpoints.
- Accept constructive criticism. Focus on what is best for the community.
- Show empathy toward others.

## Unacceptable behavior

- Harassment, trolling, insulting comments, personal attacks.
- Publishing others' private information without permission.
- Any conduct that would reasonably be considered inappropriate in a professional setting.

## Enforcement

- Violations may result in warning, temporary ban, or permanent ban from issues, PRs, and discussions.
- Report to the maintainers via GitHub Issues (for public matters) or repository contact for private matters. All reports are reviewed confidentially.

## Scope

Applies in all project spaces (repo, issues, PRs, discussions) and when representing the project publicly.
